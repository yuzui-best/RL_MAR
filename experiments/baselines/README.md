# Comparison methods

The public distribution includes sanitized baseline implementation snapshots:

| Method | Reference | Distribution note |
| --- | --- | --- |
| Direct Generation | Single-pass generation with the selected model | Runner snapshot included; source license was not identified. |
| AutoPLC | [Upstream repository](https://github.com/cangkui/AutoPLC) | Local ST/SCL adaptation included with its upstream notice. |
| LLM4PLC | [Upstream repository](https://github.com/fakih-/LLM4PLC) | Local adaptation included; exact source commit and license remain unresolved. |

Aggregate comparisons describe saved experiments. An upstream checkout alone
does not identify the exact adaptation, provider settings, evaluator or run
archive used for those results. Machine paths and private network addresses
have been replaced with local configuration. Each supplied artifact retains
its own terms; inclusion does not resolve an unclear license.
